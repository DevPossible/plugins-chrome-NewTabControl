## [0.1.0] - 2026-08-09

### Added

- New tab override with a configurable target address, defaulting to the
  DevPossible Start Page.
- Redirect and embed modes, with detection and a clear message when a site
  refuses to be framed.
- Options page, also reachable as the toolbar popup.
- Packaging scripts with a dependency-free ZIP writer, and a validation step
  that enforces the permissions allowlist and Chrome Web Store listing limits.
